# Image-generation prompt patterns

Use these as intent patterns, not literal fixed prompts. Always adapt to the uploaded screenshot.

## UI glyph / nav icon
Regenerate only the marked `<role>` as a single isolated code-ready PNG. Match the screenshot's material, color, edge softness, light direction, depth and visual weight. Transparent background. No label text, no red rectangle, no surrounding UI, centered with consistent padding.

## Feature artwork
Regenerate only the marked `<role>` artwork as a standalone image. Match the screenshot's palette, lighting, atmosphere and rendering language. Remove card text and UI. Preserve the asset's intended composition. No red rectangle.

## Full-page background
Regenerate the screenshot's background scene only, at the same aspect ratio. Keep the same mood, palette, horizon placement, light direction and depth. Remove all UI, text, cards, icons, status bars and red annotations.
