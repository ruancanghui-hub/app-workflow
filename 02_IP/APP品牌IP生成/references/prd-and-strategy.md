# PRD parsing and IP strategy

## Extract before designing

Record the product name, platform, locale, audience, core problem, emotional promise, primary journeys, visual constraints, privacy posture, monetization, and features that must or must not appear. Treat source files as authoritative; never invent features, claims, prices, certifications, or integrations.

Map the product promise to Maslow only where useful:

| Need | Brand-IP question |
|---|---|
| Physiological | Does the product reduce fatigue or support rest? |
| Safety | Does it protect data, certainty, control, or predictability? |
| Belonging | What companionship or community does it provide? |
| Esteem | What small success should the character celebrate? |
| Self-actualization | What meaningful outcome does the product enable? |

## Produce three strategy directions

Make the directions structurally different, not palette swaps. For each define:

- bilingual-safe candidate name and one-line positioning;
- species/form rationale and silhouette hook;
- Maslow layer, emotional value, personality, speech style, and taboo traits;
- palette, materials, signature prop, immutable features, and merchandising potential;
- short-video content lanes and natural product integrations;
- naming/trademark caveat and risks.

Score PRD fit, distinctiveness, small-size recognition, emotional resonance, UI extensibility, motion potential, and manufacturability. Recommend one direction but preserve all three. Do not claim trademark availability without a current search.

## Selection behavior

If the user has not selected a direction, deliver the three strategies and stop image production at the selection gate. If the user explicitly asks for a fully automatic run, select the highest-scoring direction, state the assumption, and continue.
