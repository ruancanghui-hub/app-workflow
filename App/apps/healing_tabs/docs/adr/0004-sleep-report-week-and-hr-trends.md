# 睡眠报告周视图与独立心率趋势

Status: accepted  
Supersedes（局部）: ADR-0003 中「夜间心率曲线后置」

需要跨夜睡眠趋势与跨次心率回顾时，选择 **扩展睡眠报告**（一夜详情 + 本周时长）与 **独立心率趋势页** 两套表面，而不是把睡眠与心率揉进同一报告，也不是为睡眠另开第三个「趋势」品牌页。一周为主、点 **睡眠日** 下钻；日期回顾窗口与「一周」对齐为近 7 天。

**睡眠报告**：一夜视图保留阶段图，并提前纳入该夜 **夜间心率曲线**（不再后置）。页内可切「本周」：主图为每晚总睡时长；点某日回到该夜。入口仍以戒指 Tab 摘要为主，报告内「本周」为次入口。

**心率趋势页**：与报告分离。上段按睡眠日聚合睡眠相关心率；下段近 7 天 **冥想心率** 练习列表，点进单次曲线。戒指 Tab 心率摘要卡进入本页。

**冥想心率**：不新建「冥想监测」能力；挂在冥想内容 **播放** 上——已连接时边播边采，至少一个有效采样即落记录；未配对不拦截播放、不产生曲线。

**数据诚实度**：有戒指真时序才画曲线；无时序空态说明，禁止合成曲线冒充真实监测。这与「先出好看图」的演示填充方案相对，优先避免用户误信假体征。

**未选方案**：报告内嵌周+日+心率一切；睡眠与心率共用一页双 Tab；冥想强制配对才能播；周趋势仅做心率而睡眠不做周时长。
