# 睡眠监测：强依赖戒指、双入口与阶段图报告

云遥的「睡眠监测」是面向用户的能力品牌，内含 **监测会话**（今晚进行中）与 **睡眠报告**（已结束的一夜结果）。V1 强依赖已连接戒指采集体征，不做手机传感器降级；未连接时任何入口均导向配对引导，不向用户展示伪装成真数据的演示报告。

**入口与路径**：首页「睡眠监测」卡与戒指 Tab **昨夜睡眠摘要** 共用同一流：能力 → 摘要 → 报告。用户 **显式开始** 监测，进入全屏监测会话页；页内可选 **伴睡声景** 与监测并行。一夜对应一个会话对象（在既有本地 SleepSession 上合并升级），主观星级为可选反馈，不替代戒指指标。

**结束与异常**：以手动「结束并查看报告」为主；若未结束，次日 10:00 或再次打开 App 时自动收口。进行中会话本地可恢复；超过 16 小时未结束则自动收口。统计按 **睡眠日**（切点 12:00）聚合，避免跨午夜一夜被拆成两天。

**报告内容（V1）**：时长、质量标签、分数、一句话 insight、可选主观星级，以及四阶段 **睡眠阶段** 图（深睡 / 浅睡 / REM / 清醒）。阶段图使用 [`sleep_stages_chart`](https://pub.dev/packages/sleep_stages_chart) 渲染；数据来自戒指同步的阶段段，非 HealthKit 手机降级。报告看完后主路径回戒指 Tab（摘要更新），报告内可嵌轻量体征推荐。

> **局部修订**：原「夜间心率曲线后置」已由 [ADR-0004](./0004-sleep-report-week-and-hr-trends.md) 取代——报告一夜视图纳入夜间心率曲线，并增加本周时长视图与独立心率趋势页。

**与睡眠 Tab 的边界**：睡眠 Tab 是助眠 **内容** 库；睡眠监测 / 报告是戒指 **体征**，不把报告塞进内容 Tab（延续 ADR-0001）。
