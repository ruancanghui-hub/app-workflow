# 云遥 Tab — 领域词汇表

> 仅记录业务语言，不含实现细节。睡眠标题库见 `docs/睡眠的标题.md`；冥想标题库见 `docs/冥想标题.md`。

## 睡眠 Tab

| 术语 | 定义 |
|---|---|
| **睡眠 Tab** | 底部导航「睡眠」主页面，承载今晚推荐与睡眠内容长列表。 |
| **模块标题** | 首页大板块栏目标题（痛点向 / 感受向 / 场景向 / 热门），用于运营分区，不等同于节目分类。 |
| **节目分类** | 睡眠内容的 8 类固定 taxonomy，用于长列表分组展示。 |
| **节目条目** | 分类下的单集/专辑卡片，含主标题与副标题（`主标题｜副标题`）。 |

### 节目分类（8 类）

1. **快速入睡** — 躺床睡不着时的引导练习。  
2. **半夜易醒 · 再次入睡** — 夜间惊醒后的再次入眠。  
3. **失眠焦虑** — 对抗「必须睡着」的焦虑。  
4. **睡眠故事** — 人声叙事助眠。  
5. **自然白噪音** — 环境音，无旁白。  
6. **舒眠纯音乐** — 纯配乐背景。  
7. **YogaNidra 瑜伽睡眠** — 躯体逐层放松。  
8. **午休小憩** — 白天短时恢复。

### 边界

- **模块标题**（文档第一节）≠ **节目分类**（文档第二节）：前者是运营分区话术，后者是内容 taxonomy。  
- **白噪音** 与 **舒眠纯音乐** 均无旁白，但前者偏自然声场，后者偏器乐氛围。  
- **睡眠故事** 必含人声叙事；与自然白噪音互斥。  
- **睡眠内容**（本 Tab）≠ **睡眠报告** / **睡眠监测**（戒指体征）：内容是可播放节目；监测与报告依赖已连接戒指。

## 冥想 Tab

| 术语 | 定义 |
|---|---|
| **冥想 Tab** | 底部导航「冥想」主页面，承载日间推荐与冥想内容长列表（亮色日间风格）。 |
| **模块标题** | 首页大板块栏目标题（痛点 / 感受 / 场景 / 热门），用于运营分区。 |
| **节目分类** | 冥想内容的 8 类固定 taxonomy，用于长列表分组展示。 |
| **节目条目** | 分类下的单集/专辑卡片，含主标题与副标题。 |

### 节目分类（8 类）

1. **快速减压** — 当下紧绷的即时松绑。  
2. **情绪急救** — 焦虑烦躁难过时的情绪缓冲。  
3. **自我成长** — 内心觉察、慈悲与自洽。  
4. **职场喘息** — 上班族专属减压切换。  
5. **备考静心** — 学习专注与考前安抚。  
6. **日间活力** — 晨起 / 午后能量唤醒。  
7. **社交修复** — 社交耗竭后的能量回补。  
8. **多日系列** — 循序渐进的习惯养成专辑。

### 边界

- **模块标题** ≠ **节目分类**：同睡眠 Tab。  
- 冥想偏**白天使用场景**（亮色 UI），与睡眠夜间暗色氛围区分。  
- **日间活力** 与睡眠的 **午休小憩** 不同：前者提神唤醒，后者短暂休息。

## 戒指 Tab（设备）

| 术语 | 定义 |
|---|---|
| **设备** | 可配对的可穿戴硬件上位概念（领域模型用语）。 |
| **戒指** | 用户可见的底栏名称与当前唯一设备形态；监测睡眠与心率。 |
| **戒指 Tab** | 底部导航「戒指」主页面：连接状态、今日体征摘要，以及据此推荐的云遥内容入口。 |
| **连接态** | 戒指与 App 是否已配对并可同步（未配对 / 已连接 / 同步中等）。 |
| **睡眠监测** | 面向用户的能力品牌：用已连接戒指完成一夜睡眠采集，并查看结果；对内含监测会话与睡眠报告。 |
| **监测会话** | 一次「今晚」进行中的睡眠采集过程（从开始监测到结束出结果）。 |
| **昨夜睡眠摘要** | 戒指测得的上一夜睡眠概览（时长、质量一句话等），非节目内容；戒指 Tab 上的一句话入口。 |
| **睡眠报告** | 已结束的一夜监测结果详情页；由摘要或监测流程进入，不属于睡眠内容库。 |
| **睡眠阶段** | 一夜睡眠切分出的状态段：深睡、浅睡、REM、清醒；在睡眠报告中以阶段图展示。 |
| **心率读数** | 戒指测得的心率展示（V1：静息或实时择一展示）。 |
| **体征推荐** | 根据摘要指标推荐的睡眠/冥想节目入口。 |
| **伴睡声景** | 监测会话进行中可选播放的助眠音频；挂在会话上，不替代体征采集。 |
| **睡眠日** | 以中午 12:00 为切点的统计窗口；前一中午至后一中午归属同一夜，避免跨午夜被拆成两天。 |

### 边界

- 用户文案用 **戒指**；扩展多形态硬件时领域仍称 **设备**。  
- **戒指 Tab** ≠ **睡眠 Tab**：前者是体征与硬件；后者是助眠内容。  
- **睡眠监测** ≠ **睡眠内容**：监测依赖已连接戒指的体征采集；内容是可播放节目。  
- **睡眠监测** 强依赖 **连接态=已连接**；V1 不做手机传感器降级监测。  
- 未连接时点任何睡眠监测入口 → **配对引导**（不展示伪装成真数据的演示报告）。  
- 用户路径：**睡眠监测**（能力）→ **昨夜睡眠摘要**（一句话）→ **睡眠报告**（详情）。  
- 主入口为 **双入口**：首页「睡眠监测」与戒指 Tab 摘要共用同一监测/报告流。  
- **监测会话** 由用户 **显式开始**；进入 **全屏监测会话页**（进行中态），可从页内选择 **伴睡声景** 并行播放。  
- **监测会话**（进行中）≠ **睡眠报告**（已结束结果）；一夜对应一个会话对象（合并升级既有本地会话模型）。  
- 会话 **结束**：以用户手动「结束并查看报告」为主；若未结束，次日 10:00 或再次打开 App 时自动收口出报告。  
- **睡眠日** 切点为 **12:00**；阶段图与摘要按睡眠日聚合。  
- App 被杀或离线：**进行中会话可恢复**；若持续超过 16 小时未结束则自动收口。  
- V1 **睡眠报告** 必含：时长、质量标签、分数、一句话 insight、可选主观星级，以及 **睡眠阶段** 图（深睡 / 浅睡 / REM / 清醒）。夜间心率曲线后置。  
- 报告看完后的主路径：回 **戒指 Tab**（摘要已更新），报告内可嵌轻量 **体征推荐**。  
- V1 戒指 Tab 指标仍以 **昨夜睡眠摘要 + 心率** 为主；阶段细节在报告页展开。  
- 原「声音」底栏已撤除；声景仍可通过首页场景、播放器与声景库进入，不占底栏。

## 我的页（身份与资产）

| 术语 | 定义 |
|---|---|
| **我的页** | 从首页顶栏头像进入的全屏页：身份、使用摘要、内容资产、戒指入口与设置合规。 |
| **设备身份** | 首次打开 App 时为本机生成的账号身份；用户无感登录，不依赖手机号/第三方。 |
| **本机云遥账号** | 设备身份在界面上的称呼；可改昵称与头像展示。 |
| **绑定账号** | 后置能力：将设备身份关联到手机号等，便于换机同步（V1 仅弱入口）。 |
| **使用摘要** | 本机使用概况（如连续使用天数、收藏数、最近一次练习）。 |
| **播放历史** | 本机近期播放过的节目列表。 |
| **内容资产** | 用户在本机积累的收藏与历史等可再进入的内容入口。 |

### 边界

- **我的页** ≠ 底栏 Tab：由头像进入，不占第五席。  
- **设备身份** ≠ 旧「游客模式」开关：一律本机身份，不再提供游客开关。  
- **设备身份** ≠ **绑定账号**：前者开箱即有；后者可选、后置。  
- 戒指体征详情仍在 **戒指 Tab**；我的页仅一行连接态入口。  
- 会员/试用中心 V1 不进我的页（仍可在播放器出现）。
