# 云遥 Tab — 领域词汇表

> 仅记录业务语言，不含实现细节。睡眠标题库见 `docs/睡眠的标题.md`；冥想标题库见 `docs/冥想标题.md`。

## 睡眠 Tab

| 术语 | 定义 |
|---|---|
| **睡眠 Tab** | 底部导航「睡眠」主页面，承载今晚推荐与睡眠内容长列表。 |
| **模块标题** | 首页大板块栏目标题（痛点向 / 感受向 / 场景向 / 热门），用于运营分区，不等同于节目分类。 |
| **节目分类** | 睡眠内容的 8 类固定 taxonomy，用于长列表分组展示。 |
| **节目条目** | 分类下的单集/专辑卡片，含主标题与副标题（`主标题｜副标题`）。 |

### 节目分类（8 类）

1. **快速入睡** — 躺床睡不着时的引导练习。  
2. **半夜易醒 · 再次入睡** — 夜间惊醒后的再次入眠。  
3. **失眠焦虑** — 对抗「必须睡着」的焦虑。  
4. **睡眠故事** — 人声叙事助眠。  
5. **自然白噪音** — 环境音，无旁白。  
6. **舒眠纯音乐** — 纯配乐背景。  
7. **YogaNidra 瑜伽睡眠** — 躯体逐层放松。  
8. **午休小憩** — 白天短时恢复。

### 边界

- **模块标题**（文档第一节）≠ **节目分类**（文档第二节）：前者是运营分区话术，后者是内容 taxonomy。  
- **白噪音** 与 **舒眠纯音乐** 均无旁白，但前者偏自然声场，后者偏器乐氛围。  
- **睡眠故事** 必含人声叙事；与自然白噪音互斥。  
- **睡眠内容**（本 Tab）≠ **睡眠报告** / **睡前放松**（休息体征）：内容是可播放节目；报告来自 Apple 健康，放松会话是伴睡流程。

## 冥想 Tab

| 术语 | 定义 |
|---|---|
| **冥想 Tab** | 底部导航「冥想」主页面，承载日间推荐与冥想内容长列表（亮色日间风格）。 |
| **模块标题** | 首页大板块栏目标题（痛点 / 感受 / 场景 / 热门），用于运营分区。 |
| **节目分类** | 冥想内容的 8 类固定 taxonomy，用于长列表分组展示。 |
| **节目条目** | 分类下的单集/专辑卡片，含主标题与副标题。 |

### 节目分类（8 类）

1. **快速减压** — 当下紧绷的即时松绑。  
2. **情绪急救** — 焦虑烦躁难过时的情绪缓冲。  
3. **自我成长** — 内心觉察、慈悲与自洽。  
4. **职场喘息** — 上班族专属减压切换。  
5. **备考静心** — 学习专注与考前安抚。  
6. **日间活力** — 晨起 / 午后能量唤醒。  
7. **社交修复** — 社交耗竭后的能量回补。  
8. **多日系列** — 循序渐进的习惯养成专辑。

### 边界

- **模块标题** ≠ **节目分类**：同睡眠 Tab。  
- 冥想偏**白天使用场景**（亮色 UI），与睡眠夜间暗色氛围区分。  
- **日间活力** 与睡眠的 **午休小憩** 不同：前者提神唤醒，后者短暂休息。

## 休息 Tab（Apple 健康）

| 术语 | 定义 |
|---|---|
| **数据来源** | 体征数据的上位概念；当前唯一来源为 Apple 健康（含 Apple Watch、iPhone 或第三方写入的样本）。 |
| **休息 Tab** | 底部导航「休息」主页面（仅 iOS）：健康授权态、昨夜睡眠摘要、心率读数，以及推荐的云遥内容入口。 |
| **健康授权态** | App 是否已请求并可用 Apple 健康读权限：未连接 / 已连接有数据 / 已连接暂无数据。 |
| **睡前放松** | 面向用户的能力品牌：伴睡声景 + 定时的全屏会话；不负责采集体征，与睡眠报告解耦。 |
| **放松会话** | 一次「今晚」进行中的睡前放松过程（从开始到结束）；可挂伴睡声景。 |
| **昨夜睡眠摘要** | 来自 Apple 健康的上一夜睡眠概览（时长、阶段占比一句话等），非节目内容；休息 Tab 上的一句话入口。 |
| **睡眠报告** | 某一睡眠日的休息结果详情页；含一夜详情与可切换的「本周」视图；按睡眠日读 Apple 健康，不属于睡眠内容库。 |
| **睡眠阶段** | 一夜睡眠切分出的状态段：深睡、浅睡、REM、清醒；在睡眠报告一夜视图中以阶段图展示。 |
| **心率读数** | 休息 Tab 摘要卡上的单点心率（优先静息心率，否则最近一次并标注时间），不是曲线。 |
| **夜间心率曲线** | 某一 **睡眠日** 整夜心率随时间变化的曲线；嵌在睡眠报告一夜视图，并进入心率趋势页的睡眠段。 |
| **心率趋势页** | 独立详情页：上段按睡眠日看睡眠相关心率，下段按次看冥想播放记录对应的心率曲线；与睡眠报告分离。 |
| **播放记录** | 一次冥想节目播放留下的本地时间窗（起止时刻与内容元数据）；不含心率数值。 |
| **冥想心率曲线** | 某条 **播放记录** 时间窗内、从 Apple 健康查到的心率时序；有样本才画。 |
| **体征推荐** | 根据摘要指标推荐的睡眠/冥想节目入口（提审版不做个性化）。 |
| **伴睡声景** | 放松会话进行中可选播放的助眠音频；挂在会话上。 |
| **睡眠日** | 以中午 12:00 为切点的统计窗口；前一中午至后一中午归属同一夜，避免跨午夜被拆成两天。 |

### 边界

- 用户文案用 **休息** / **Apple 健康**；领域称 **数据来源**，不再称戒指或设备硬件。  
- **休息 Tab** ≠ **睡眠 Tab**：前者是体征与授权；后者是助眠内容。仅 iOS 显示休息 Tab。  
- **睡前放松** ≠ **睡眠内容**：放松是伴睡会话；内容是可播放节目。  
- **睡前放松** **不**依赖健康授权；任何人可直接开始，未授权时会话页不显示心率 pill。  
- **睡眠报告** 来自 Apple 健康按 **睡眠日** 聚合，与是否开过放松会话无关。  
- 未连接时点报告 / 心率入口 → **连接 Apple 健康** 引导（不展示伪装成真数据的演示报告）。  
- 用户路径：休息 Tab **昨夜睡眠摘要** → **睡眠报告**；首页「睡前放松」进会话，不挡报告。  
- **放松会话** 由用户 **显式开始**；进入全屏会话页，可从页内选择 **伴睡声景**。  
- **放松会话**（进行中）≠ **睡眠报告**（健康结果）；会话结束不生成假体征。  
- 会话 **结束**：以用户手动结束为主；若未结束，次日 10:00 或再次打开 App 时自动收口。  
- **睡眠日** 切点为 **12:00**；阶段图与摘要按睡眠日聚合。  
- App 被杀或离线：**进行中放松会话可恢复**；若持续超过 16 小时未结束则自动收口。  
- **睡眠报告** 展示真实字段：时长、阶段占比中性一句话、**有真数据才显示的睡眠阶段** 图，以及该夜 **夜间心率曲线**。无分数、无优劣质量标签；无阶段时不以演示数据填充。  
- **睡眠报告** 支持一夜 / **本周** 切换：本周以每晚总睡时长为主图；点某 **睡眠日** 回到该夜详情。  
- **心率趋势页** ≠ **睡眠报告**：前者聚合跨夜睡眠心率与跨次 **冥想心率曲线**；后者以一夜为主，内嵌周时长。  
- **心率趋势页** 布局：上段睡眠相关（按 **睡眠日**），下段冥想相关（近 7 天 **播放记录** 列表，点进该次曲线）。  
- **播放记录** 在冥想内容 **播放结束** 时落本地时间窗；查看曲线时再查 Apple 健康。  
- 未授权也可播放冥想内容；无样本则空态，不拦截播放。  
- 报告「本周」、心率趋势与日期选择的回顾窗口为 **近 7 个睡眠日 / 近 7 天**。  
- **心率读数**（摘要单点）≠ **夜间心率曲线** / **冥想心率曲线**（时序）。  
- 曲线数据：**有真时序才画**；无时序则空态说明，禁止用合成曲线冒充真实监测。  
- 会话页心率 pill：仅当最近一次心率样本不超过 15 分钟时显示。  
- **本轮提审**：睡眠/冥想 Tab 的 **节目条目** 仅收录标题与可播素材一致的自然声景；休息 Tab「推荐聆听」不为「根据体征」个性化。  
- 主入口：休息 Tab 摘要进报告 / 心率趋势；睡眠报告内可进「本周」。  
- 报告看完后的主路径：回 **休息 Tab**。  
- 原「声音」底栏已撤除；声景仍可通过首页场景、播放器与声景库进入，不占底栏。

## 我的页（身份与资产）

| 术语 | 定义 |
|---|---|
| **我的页** | 从首页顶栏头像进入的全屏页：身份、使用摘要、内容资产、Apple 健康入口与设置合规。 |
| **设备身份** | 首次打开 App 时为本机生成的账号身份；用户无感登录，不依赖手机号/第三方。 |
| **本机云遥账号** | 设备身份在界面上的称呼；可改昵称与头像展示。 |
| **绑定账号** | 后置能力：将设备身份关联到手机号等，便于换机同步（V1 仅弱入口）。 |
| **使用摘要** | 本机使用概况（使用天数、收藏数、最近一次真实睡眠记录摘要）。 |
| **播放历史** | 本机近期播放过的节目列表；无记录时为空态，不展示演示条目。 |
| **内容资产** | 用户在本机积累的收藏与历史等可再进入的内容入口。 |

### 边界

- **我的页** ≠ 底栏 Tab：由头像进入，不占第五席。  
- **设备身份** ≠ 旧「游客模式」开关：一律本机身份，不再提供游客开关。  
- **设备身份** ≠ **绑定账号**：前者开箱即有；后者可选、后置。  
- 体征详情仍在 **休息 Tab**；我的页仅一行健康授权态入口；撤销授权在系统「健康」App。  
- 会员/试用中心提审版本不出现在播放器与我的页。
