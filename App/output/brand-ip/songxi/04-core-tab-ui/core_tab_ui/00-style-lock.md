# 松息 Core Tab UI 锁定

- 批准源：`../direction-01-light-brand-generated-raw.png`
- 画布：853 × 1844 px
- 根导航：`今晚 → 声音 → 睡眠 → 我的`
- 颜色：暖雾白背景、深松绿主色、琥珀激活强调、灰鼠尾草辅助
- 材质：哑光纸张/软陶、柔和下投影、有机卵石圆角
- 字体层级：超大深绿页标题；深绿卡片标题；中灰辅助文案
- 图标：深绿线性图标；激活项以深松绿承载并使用琥珀细节
- 吉祥物：仅在欢迎、开始睡眠或账户人格化区域克制出现；必须沿用角色锚点

## 根页需求

| 文件 | 根 Tab | P0 内容 |
|---|---|---|
| `tab-tonight.png` | 今晚 | 推荐声景、开始今晚、快捷呼吸 |
| `tab-sounds.png` | 声音 | 免费/锁定声景、收藏、下载、离线入口 |
| `tab-sleep.png` | 睡眠 | 会话、轻唤醒、基础报告、最近记录 |
| `tab-profile.png` | 我的 | 游客态、会员、下载、权限、隐私设置 |

## 实施约束

PNG 用于视觉方向，不作为可编辑组件来源。第三阶段必须以一个共享 Tab 组件实现四页，组件输入只有 `activeTab` 可以变化。
