# 松息品牌 IP — PRD Brief

- 产品：松息（songxi）
- 平台：iOS 优先，MVP 简体中文
- 用户：25–45 岁、睡眠困扰或高压的城市成人
- 定位：用原创自然声景与睡前仪式，帮助成人进入睡眠并温和醒来
- MVP 闭环：选声景 → 开启睡眠会话 → 轻唤醒 → 查看基础报告
- 商业模式：免费核心闭环 + 订阅扩展声景库
- 核心 Tab：今晚
- 核心情绪：安全、减压、可预测、不过度兴奋的陪伴
- 品牌任务：建立一个成人化、低刺激、可扩展到声音、呼吸、睡眠报告与轻唤醒的原创角色系统

## 视觉与内容约束

- 不复制潮汐或任何现有角色、图标、UI、插画、文案与音频。
- 健康表述限定为辅助放松与自我觉察，不出现诊断、治疗或睡眠分期暗示。
- 角色应在 App Icon 小尺寸、深色夜间界面与浅色报告界面中保持识别。
- UI 只展示 MVP 已定义的信息架构和功能：今晚、声音、睡眠、我的，以及快捷呼吸。
- 不加入社交、AI 睡眠分析、Watch、故事、冥想课、番茄专注等非 MVP 能力。
- 视觉应适合夜间使用：克制对比、少量暖色反馈、避免强刺激和幼儿化表达。

## 成功标准

1. 角色无需文字即可识别。
2. 所有衍生资产保持同一松果种子精灵身份。
3. 图标在小尺寸下保持清晰轮廓。
4. 角色物理语言能转译为 UI 色彩、圆角、材质、进度和状态动效。
5. 三套核心 Tab 方向均可被真实 iOS 产品实现。
