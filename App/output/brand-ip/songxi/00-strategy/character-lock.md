# 松芽 Songya — Canonical Character Lock

状态：已锁定。

- 选定锚点：`../01-character-concepts/character-anchor.png`
- 来源概念：Concept 05 — Geometric Pulp
- 实际尺寸：1672 × 941 px
- 选择理由：几何松籽轮廓清晰，3D/2D 一致性最好，三瓣额纹、双叶耳与息环在小尺寸下稳定。

## 不可变身份

- 物种：原创松果种子精灵，不对应真实动物。
- 主轮廓：上窄下圆的柔和水滴形；头身一体，头部约占整体 55%。
- 耳朵：头顶两片短小松针叶耳，向外微弯，不能变成长兽耳或鹿角。
- 额部：仅三瓣大号松鳞符号，禁止铺满细碎松果纹理。
- 眼睛：两枚深夜蓝半闭椭圆眼；无明显眼白、睫毛或眉毛。
- 面部：无突出鼻吻；仅一个极短、低对比的小弧形嘴。
- 四肢：短圆手臂与短圆脚，完整可见；无手指细节、鞋或服装。
- 胸前标记：单一暖琥珀色圆环“息环”，中心为空，不得变成宝石、按钮或文字。
- 默认表情：安静、轻微满足，不困倦失神。

## 色彩与材质

- 主体深松绿：`#183D35`
- 阴影夜蓝：`#101A2A`
- 面部与腹部雾白：`#DDE8DE`
- 息环暖琥珀：`#F2C879`
- 极少量陶土反馈色：`#C98263`
- 主材质：低反射植绒或细腻毡面；允许哑光陶瓷面部细节。
- 锚点主材质：低反射压缩纸浆质感外壳与细毡面部嵌片；后续可在不改变轮廓的前提下模拟为植绒产品材质。
- 光线：低刺激、柔和侧顶光；息环只产生局部暖光。

## 允许探索的变量

- 植绒长短、毡面密度、陶瓷占比。
- 身体宽度与脚掌大小可在约 10% 范围内变化。
- 三瓣额部松鳞可在圆润与略几何之间变化。
- 2D 表现可使用平涂或轻微纸感，但轮廓和色值关系必须一致。

## 禁止漂移

- 不增加帽子、围巾、翅膀、尾巴、背包、武器或自然景物道具。
- 不变成熊、兔、猫、鹿、松鼠或已知商业角色。
- 不采用霓虹、高饱和糖果色、亮面塑料、重金属或复杂渐变。
- 不出现文字、徽标、水印、医疗符号、星月贴纸或睡帽陈词滥调。
- 不改变息环位置、耳朵数量、额部三瓣结构或半闭眼特征。
