# 节庆祝福 产品需求文档（PRD）

- 产品名：节庆祝福
- 模式：智能模式
- 平台：iOS 优先（首发 iPhone）
- 目标用户：18+ 需要在节庆节点快速制作祝福贺卡的中文用户
- 商业策略：MVP 全免费游客体验；订阅解锁高级模板 defer 至 MVP+1
- 版本：V1.0
- 日期：2026-08-30
- 状态：MVP 规划

## 1. 背景与机会

节庆节点用户频繁在微信群、朋友圈发送祝福，但现成图片同质化、自制贺卡工具过重。轻量「模板 + 祝词 + 一键导出」有明确场景。机会在于：**比 Canva 更短路径、比纯图库更个性化**，且以原创模板建立品牌。

## 2. 产品定位

### 2.1 一句话定位

节庆祝福是一款 iOS 贺卡工具：帮你在一分钟内选出节日模板、写好祝词并保存或分享。

### 2.2 价值主张

零门槛制作体面贺卡；无需注册；导出高清图即可发微信。

### 2.3 产品原则

1. 节日场景优先于通用设计能力。  
2. 模板与文案必须可证明权属。  
3. 主路径 5 步内完成。  
4. 权限拒绝仍可完成预览（仅保存需相册权）。  
5. 订阅不阻断 MVP 闭环。

## 3. 用户与 JTBD

### 3.1 主要用户

18–50 岁中文用户，节庆前 1–7 天需要给亲友发祝福。

### 3.2 核心任务（JTBD）

当春节/中秋等节日临近时，帮我快速做一张好看、带我个人祝词的贺卡，并保存或分享到微信。

## 4. 目标与非目标

### 4.1 产品目标

- TestFlight 验证 MVP 闭环完成率。  
- 建立可扩展模板与发布流水线（复用 app-workflow）。

### 4.2 非目标

- 不做通用 PS 级编辑器。  
- MVP 不做订阅、账号、AI 生成祝词。  
- 不做 Android 对等首发。

## 5. 成功指标

| 指标 | 口径 | 初始目标 |
|---|---|---|
| 激活 | 安装后 24h 内完成首张贺卡导出 | ≥35% |
| 闭环 | 选模板→编辑→保存或分享 | ≥50% 开始用户 |
| 崩溃率 | 会话中崩溃 | <0.5% |
| TestFlight | 上传成功 + 内部 smoke | 100% |

## 6. 信息架构

一级 Tab（MVP）：

1. **首页** — 当前节日推荐、快捷制作。  
2. **模板** — 按节日分类的模板库。  
3. **我的** — 已保存贺卡历史。  
4. **设置** — 游客说明、隐私、关于。

## 7. 核心流程

1. 冷启动 → 首页推荐节日 → 选模板。  
2. 编辑祝福语与署名 → 实时预览。  
3. 保存相册 / 系统分享 → 写入「我的」。  
4. 拒相册权限 → 仍可调起分享（若系统允许）并提示开启权限以保存。

## 8. 功能需求

### 8.1 模板库（P0）

浏览、预览、选择；≥6 套 bundled 模板；空态与加载态。

### 8.2 编辑器（P0）

多行 TextField、默认祝词、字数软提示；不支持复杂图层编辑。

### 8.3 预览与导出（P0）

Widget 合成或预渲染 PNG；`image_gallery_saver` / `share_plus` 或等价方案。

### 8.4 我的贺卡（P0）

本地列表 SharedPreferences + 文件缓存缩略图。

### 8.5 设置（P0）

游客模式说明、隐私弹窗、版本号。

### 8.6 订阅（defer）

P1：StoreKit 产品页与付费模板锁。

## 9. 业务规则

- 全部 bundled 模板 MVP 免费。  
- 导出图片带 App 可选角标（可关闭，P1）。  
- 模板上下架不影响已保存贺卡查看。

## 10. 数据与隐私

| 数据 | 目的 | 存储 | 说明 |
|---|---|---|---|
| 贺卡记录 | 回访 | 本机 | 不上传 |
| 编辑草稿 | 恢复 | 本机 | 可选 |
| 分析 | 改进 | 可选 Firebase | MVP 可关闭 |

需提供隐私说明；相册仅用于写入导出图。

## 11. 异常与降级

无网可用 bundled 模板；导出失败可重试；相册拒权引导设置。

## 12. 非功能需求

冷启动 <2s；预览合成 <1s（静态模板）；iOS 16+；支持 Dynamic Type 基础。

## 13. 商业化与增长

MVP 免费；P1 Freemium 高级模板。增长靠节日自然流量与分享图角标（可选）。

## 14. 埋点与实验

MVP 可选：模板选择、导出成功、分享渠道（若 Firebase 开启）。

## 15. 测试与发布门

`flutter test` + 主路径真机 smoke + `upload_app_store.sh` TestFlight。Info.plist 相册权限文案必填。

## 16. 风险与应对

| 风险 | 应对 |
|---|---|
| 模板版权 | 原创或授权台账 |
| 相册审核 | 明确用途字符串 |
| 与云遥同 Team 证书 | SKIP_MATCH + 自动签名 |

## 17. 版本路线

- **0.1.0** MVP TestFlight  
- **0.2.0** 订阅 + 远程模板  
- **0.3.0** 更多节日与动效
