- 产品名：疗愈（healing_tabs）

- 日期：2026-08-31
- 状态：已锁定 Grill 决策
- 上级文档：`02-PRD.md`、`03-MVP范围.md`、`睡眠和冥想.md`

## 0. 第一版验证目标

在 **两个场景** 下验证「原创白噪音 + 仪式闭环」是否成立：

| 场景 ID | 名称 | 一句话 |
|---|---|---|
| **S1** | 白噪音 + 睡眠 | 用户选一条自然白噪音，设定时、显式开始睡觉，结束后看到在床时长与评分 |
| **S2** | 白噪音 + 冥想 | 用户选时长，在白噪音底噪上跟呼吸动画练完，结束时选情绪反馈 |

**不验证**：多轨混音、睡前故事、HealthKit、冥想系列课、日历 Streak、订阅完整链路（保留 P1）。

## 1. 已锁定决策（Grill Round 1）

| # | 决策 | 选择 |
|---|---|---|
| Q1 | 播放器架构 | **共用 Player**，`scenario=sleep\|meditation` 区分结束页与叠加 UI |
| Q2 | 白噪音边界 | **单轨预设**，内置 3～6 条自然声，无混音 |
| Q3 | 睡眠会话 | **显式「开始睡觉」** 创建 `SleepSession`；播放 ≠ 会话开始 |
| Q4 | 冥想引导 | **无语音**，环境声 + 呼吸引导动画 |
| Q5 | 冥想结束 | **时长 + 情绪 3 选 1**；无 Streak |
| Q6 | 入口 | **睡眠 Tab → S1**；**冥想 Tab → S2** |

## 4. 领域术语

| 术语 | 定义 |
|---|---|
| **声景（Sound Asset）** | 单条可循环白噪音资源 |
| **播放场景（Playback Scenario）** | `sleep` \| `meditation`，决定播放器叠加层与结束页 |
| **睡眠定时器（Sleep Timer）** | 到时渐隐停播；仅 S1 |
| **睡眠会话（Sleep Session）** | 用户点「开始睡觉」到「结束」的在床记录 |
| **冥想练习（Meditation Practice）** | 单次练习：时长目标 + 白噪音 + 呼吸引导 |
| **练习小结（Practice Summary）** | 冥想结束页：时长 + 情绪 |

## 5. 场景 S1：白噪音 + 睡眠

### 5.1 主流程

```
睡眠 Tab
  → [可选] 白噪音选择页/Sheet
  → 沉浸播放器（scenario=sleep）
       ├ 播放/暂停
       ├ 睡眠定时器（15/30/45/60 + 结束前 60s 渐隐）
       └ 「开始睡觉」→ 创建 SleepSession（进行中）
  → 结束睡眠（手动 / 定时仅停播不自动结束会话——见规则）
  → 睡眠结束页：时长 + 可选 1～5 分评分
  → 睡眠历史（Sheet）
```

### 5.2 功能需求

| ID | 需求 | 规则 |
|---|---|---|
| SLP-01 | 白噪音单轨播放 | 同时仅 1 轨；默认循环；来源 `assets/sounds/` 或 CDN |
| SLP-02 | 睡眠定时器 | 快捷 15/30/45/60 min；到点前 60s 线性渐隐至静音并暂停 |
| SLP-03 | 开始睡觉 | 显式按钮；创建 `SleepSession(status=active)`；绑定当前 `soundId` |
| SLP-04 | 结束睡眠 | 写 `endedAt`；跳转睡眠结束页 |
| SLP-05 | 主观评分 | 1～5 分可选；可跳过 |
| SLP-06 | 睡眠历史 | 列表展示已结束会话：日期、时长、声景名、评分 |

### 5.3 关键规则

1. **播放 ≠ 开始睡觉**：用户可先试听，再点「开始睡觉」记会话。
2. **定时器到点**：只停播音频，**不自动结束** SleepSession（避免用户已睡着无法确认）。
3. **来电/中断**：暂停播放；恢复后延续同一会话（若仍 active）。

### 5.4 验收标准

- [ ] 从睡眠 Tab 10 分钟内完成：选声 → 播放 → 开始睡觉 → 结束 → 看到时长
- [ ] 定时器渐隐可感知，到点后音频停止
- [ ] 历史列表可见刚结束的记录
- [ ] 锁屏可暂停/继续

## 6. 场景 S2：白噪音 + 冥想

### 6.1 主流程

```
冥想 Tab
  → 选主题卡片（V1 均进入同一练习流，仅默认声景/时长可不同）
  → 练习设置 Sheet：时长 5/10/15 min + 确认声景
  → 沉浸播放器（scenario=meditation）
       ├ 白噪音底噪循环
       ├ 呼吸引导动画（4-7-8，可隐藏动画不停音频）
       └ 暂停 / 退出（二次确认）
  → 到时或手动结束
  → 练习小结：时长 + 情绪 3 选 1
```

### 6.2 功能需求

| ID | 需求 | 规则 |
|---|---|---|
| MED-01 | 单次练习 | 选时长后开始；无章节/无系列课 |
| MED-02 | 白噪音底噪 | 与 S1 共用声景目录；默认「雨声」或卡片映射 |
| MED-03 | 呼吸引导 | 默认 4-7-8 圆环缩放；开关只隐藏 UI |
| MED-04 | 练习倒计时 | 顶部或角标显示剩余时间 |
| MED-05 | 退出确认 | 退出弹窗：继续 / 结束练习 |
| MED-06 | 练习小结 | 展示实际时长 + 情绪枚举（平复/放松/仍有杂念） |
| MED-07 | 累计时长 | 本地累计总冥想分钟（无日历 Streak） |

### 6.3 验收标准

- [ ] 从冥想 Tab 完成 5 min 练习并提交情绪
- [ ] 呼吸动画与节拍可感知（约 4-7-8）
- [ ] 退出确认可防止误触离开

## 7. 共享播放器（COM）

| ID | 需求 | 规则 |
|---|---|---|
| COM-01 | 场景参数 | 路由 `/player/:soundId`，query `scenario=sleep\|meditation` |

| COM-03 | 后台与锁屏 | `just_audio` + 系统媒体控件 |
| COM-04 | 焦点抢占 | 来电暂停；结束后可恢复 |
| COM-05 | 视觉主题 | sleep=暗色沉浸；meditation=浅色/冥想页延续 |

## 12. 非功能需求

- 后台连续播放 ≥ 8h 无异常退出（真机 QA）
- 冷启动恢复：若存在 active SleepSession，睡眠 Tab 显示「进行中」入口
- 文案：wellness 表述，无医疗诊断承诺
