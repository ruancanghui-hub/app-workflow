# 松息 假设与决策

- 日期：2026-08-28
- 模式：智能模式

## 1. 用户明确提供

| 事项 | 用户信息 | 对产品的影响 |
|---|---|---|
| 模式 | 智能模式 | 最多三个关键问题；其余保守推定 |
| 竞品 | 潮汐 App Store 链接 | 功能蓝图对齐其主模块 |
| 诉求 | 想完全复刻这个 App | 长期蓝图保留对等模块；禁止素材/品牌复刻 |
| 平台 | iOS 优先 | 首发 iPhone；其他端后置 |
| 产出位置 | 写在 `App` 目录 | 文档落于 `App/docs/product/...` |

## 2. 来源确认

| 事项 | 结论 | 来源 | 对产品的影响 |
|---|---|---|---|
| 潮汐主模块 | 冥想、白噪音、故事、睡眠监测/报告、轻唤醒、专注、呼吸、离线、系统表面、Watch、订阅 | App Store 潮汐页 | 写入功能清单基线 |
| 商业模式 | 应用内订阅（Plus 等） | App Store IAP + 会员协议 | Freemium 策略 |
| 健康审核 | 无证据准确率与部分传感器测量不可宣称 | Apple Guidelines 1.4.1 / 5.1.3 | 分期/低氧等降级 R&D 或 OUT |

## 3. 技能推定

| 推定 | 采用原因 | 影响 | 可撤销方式 |
|---|---|---|---|
| 产品名「松息」，slug `songxi` | 用户未给名；需文件系统安全标识且避开潮汐商标 | 全文档与后续工程名 | 用户改名后全局替换 |
| 「完全复刻」= 功能范式对齐 + 原创品牌内容 | 版权与 skill 安全规则禁止复制资产 | MVP 不视觉山寨 | 若用户坚持侵权路径则停止交付 |
| MVP = 夜晚入睡闭环而非全站对等 | 需可验证价值环；全量内容/算法首版不可交付 | P0 收口 | 用户指定另一闭环（如专注优先） |
| 目标用户 18+ 都市睡眠困扰成人 | 竞品适合人群表述 + 保守推定 | 文案与分级 | 用户重定人群 |
| 商业策略 Freemium 订阅 | 竞品已验证模式 | 付费墙进 MVP 骨架 | 用户改买断/纯免费 |
| 最低 iOS 16 | 对齐竞品公开兼容性 | 工程基线 | 技术选型后调整 |
| 麦克风睡眠分析不进 MVP | 高风险且证据不足 | R&D 门 | 算法与隐私方案就绪后升 P1 |

## 4. 待验证事项

| 事项 | 风险 | 验证方式 | 最晚验证阶段 |
|---|---|---|---|
| 用户是否接受原创品牌而非视觉复刻 | 期望冲突 | 本轮 PRD 评审确认 | Phase 1 结束前 |
| 音频内容自制 vs 采购授权 | 进度/成本 | 内容清单与合同 | Phase 2/3 前 |
| 收据校验后端形态 | 盗版/掉单 | 技术方案 spike | Phase 4 |
| 整夜后台音频稳定性 | 核心体验 | 真机 8h+ | Phase 6 |
| 上架主体与地区合规 | 商店拒审 | 法务清单 | Phase 7 |

## 5. 已否决方向

- 复制潮汐名称、商标、图标、界面、插画、音频、故事或文案。  
- MVP 宣称临床睡眠分期、呼吸暂停/低氧诊断或疗效。  
- 将「完全复刻」解释为可跳过版权台账。
