# 松息 功能清单

- 产品名：松息
- 模式：智能模式
- 平台：iOS 优先（首发 iPhone；iPad / Apple Watch / Mac / Android 后置）
- 目标用户：睡眠困扰、高压都市成人（18+），希望用声音与睡前仪式改善入睡与作息
- 商业策略：免费核心体验 + 订阅解锁完整内容库（Freemium）
- 版本：V1.0
- 日期：2026-08-28

## 3. 竞品基线

竞品：**潮汐（Tide）**，开发者 Moreless / 广州多少网络科技；App Store 分类健康健美；支持 iPhone/iPad/Mac/Watch；含 IAP 订阅。来源：[App Store 潮汐](https://apps.apple.com/cn/app/id1077776989)、[Google Play 潮汐](https://play.google.com/store/apps/details?id=io.moreless.tide)、[会员协议](https://tide.fm/pages/general/terms-of-member/zh-hans)。

已核实主模块：正念冥想、自然白噪音、睡眠故事、睡眠/小憩与报告、轻唤醒、番茄专注计时、呼吸法、离线、小组件/系统表面、Watch 能力、订阅会员（声音场景与冥想课等权益）。竞品宣称的「机器学习睡眠分期」「梦话鼾声识别」「低氧/呼吸异常」「全球 3000 万人」等属**竞品自述**，未独立核验。

## 4. 用户特色

用户诉求为「完全复刻潮汐」。产品决策：

- **保留**：潮汐级主模块作为长期蓝图（P1/P2），信息架构对齐「声音 + 睡眠 + 冥想/呼吸 + 专注 + 报告」。
- **差异化硬约束**：品牌名、图标、UI、插画、音频、故事、文案、动效一律原创或合法授权；不得抄袭潮汐商标与素材（见 `research-and-safety.md` §8）。
- **MVP 收口**：首发验证「睡前声音 → 睡眠会话 → 轻唤醒 → 晨间报告」闭环，而非首版堆齐全站内容库与算法监测。

## 5. 公共基础与合规

账户（可访客后登录）、麦克风/通知/后台音频权限、内容 CDN 与缓存、StoreKit 订阅、崩溃与基础分析、隐私政策与同意、本地优先敏感音频、错误/权限降级、无障碍基础（Dynamic Type/VoiceOver 关键路径）、运营配置（内容上下架）。健康数据不得用于广告定向（[App Store Review Guidelines 5.1.3](https://developer.apple.com/app-store/review/guidelines/#health-and-health-research)）。

## 6. 明确不做或 R&D

| 能力 | 结论 | 原因 | 转入正式版本的门槛 |
|---|---|---|---|
| 复刻潮汐品牌/UI/音频/故事 | OUT | 版权与商标风险 | 永不进入；仅允许功能范式借鉴 |
| 麦克风分期/鼾声/梦话识别 | R&D | 算法证据与隐私成本高 | 本地处理方案、准确率披露、真机整夜稳定性门 |
| 呼吸异常/低氧风险告警 | OUT/R&D | 近临床主张；Guideline 1.4.1 | 监管与证据齐全前禁止宣称 |
| 血压/血氧等仅靠手机传感器 | OUT | Guideline 1.4.1 明确限制 | 不适用 |
| ADHD 治疗效果宣称 | OUT | 医学宣称风险 | 仅作通用专注工具文案 |
| Android / Watch 首发对等 | OUT（MVP） | 平台定为 iOS 优先 | P2 独立里程碑 |
| 儿童专属模式 | OUT | 未确认未成年人产品意图 | 若进入需 Kids/监护合规门 |

## 7. 分期摘要

- **MVP**：原创品牌壳 + 白噪音（少量）+ 呼吸引导 + 睡眠/小憩会话 + 轻唤醒 + 基础报告（无麦克风算法）+ 离线缓存 + 订阅骨架。
- **P1**：冥想课、睡眠故事、混音、番茄专注、账号同步、小组件、麦克风睡眠分析（若 R&D 过门）。
- **P2**：空间音频、Watch、HRV 洞察、分享卡、更丰富系统表面与内容运营。
- **R&D**：自研/第三方睡眠音频算法、诊断向主张。
