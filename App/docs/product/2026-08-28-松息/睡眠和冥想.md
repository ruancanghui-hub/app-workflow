### 1. 睡眠模块 (Sleep & Soundscapes)

#### 1.1 核心流程

```
[首页 / 睡眠 Tab] 
  └── 选择音频分类 (助眠音乐 / 白噪音 / 睡前故事)
       └── 展开音频列表/卡片
            └── 点击进入播放界面 (全屏 / 沉浸暗色调)
                 ├── 独立音量调节 (多音轨混音)
                 ├── 定时关闭设置 (Sleep Timer)
                 └── 点击播放/暂停

```

#### 1.2 功能需求表

| 功能点 | 需求描述 | 详细规则/交互 |
| --- | --- | --- |
| **音频库与分类** | 多维度展示助眠资源 | • 分类包括：自然白噪音、脑波音乐（Alpha/Delta）、睡前故事、ASMR。<br>

<br>• 支持标签筛选（如：雨声、篝火、深睡、缓解焦虑）。 |
| **自定义混音器 (DIY Studio)** | 允许用户自由组合多轨音效 | • **多音轨叠加**：支持同时播放最多 4-5 种音效（如：大雨 + 雷声 + 篝火 + 钢琴）。<br>

<br>• **独立音量**：每个音轨具备独立音量滑块调节。<br>

<br>• **预设保存**：用户可将搭配好的混音保存为“我的自定义睡眠氛围”。 |
| **沉浸式播放器** | 专为夜间设计的低光度界面 | • 全屏暗色系/夜间模式 UI，降低眼部疲劳。<br>

<br>• 动态视觉背景（微动粒子、慢速呼吸波浪等）。<br>

<br>• 基础控制：播放/暂停、上一首/下一首、收藏。 |
| **睡眠定时器** | 自动停止播放，防止耗电和扰眠 | • 提供快捷选项：15/30/45/60分钟、播完当前音频、自定义时长。<br>

<br>• **渐隐效果 (Fade-out)**：倒计时结束前 1 分钟，音量平滑线性递减至静音。 |
| **睡眠记录与分析 (轻量版)** | 记录用户睡前习惯与时长 | • 点击“开始睡觉”自动触发定时播放。<br>

<br>• 结合系统 HealthKit/Google Fit 或手机麦克风，记录入睡时长与睡眠质量报告。 |

### 2. 冥想模块 (Guided Meditation)

#### 2.1 核心流程

```
[冥想 Tab] 
  └── 选择冥想主题/课程组 (如：7天基础练习)
       └── 进入课程详情页 (展示章节/导师/时长)
            └── 点击开始练习
                 └── 引导式播放界面 (伴随呼吸指示器)
                      ├── 暂停 / 退出提示
                      └── 练习完成页
                           ├── 打卡卡片生成
                           └── 情绪/感受反馈记录

```

#### 2.2 功能需求表

| 功能点 | 需求描述 | 详细规则/交互 |
| --- | --- | --- |
| **结构化冥想课程** | 系统化的音频引导路线 | • 支持“单曲练习”与“多天系列课”（如：新手入门7天、高效专注、情绪疗愈）。<br>

<br>• 课程卡片清晰标示：时长（如 5min / 10min）、难度等级、导师名字。 |
| **动态呼吸引导视觉** | 辅助语音引导的视觉与触觉反馈 | • **视觉组件**：提供呼吸波浪或扩散圆环，随吸气/呼气节奏缩放。<br>

<br>• **触觉反馈**：配合手机震动马达，在吸气/呼气节点提供轻柔震动提示。 |
| **练习完成与情绪打卡** | 闭环记录与心理正向激励 | • **情绪选择**：练习结束后提供 3-5 种情绪图标（平复、放松、焦虑减轻等）供用户勾选。<br>

<br>• **时长统计**：自动将本次练习时长累计入“总冥想时长”与“连续打卡天数”。 |
| **日历与连续打卡 (Streak)** | 提高用户粘性与习惯养成 | • **习惯追踪**：日历视图展示打卡热力图。<br>

<br>• **补签卡/提醒**：自定义每日冥想提醒时间（如早晨起床后、睡前）。 |

### 3. 通用与系统级需求

* **后台播放与锁屏控制**：支持系统锁屏界面卡片展示（封面、标题、进度条、播放/暂停控制），退至后台时不中断播放。
* **离线下载**：允许用户下载常用的睡眠音频和冥想课程，在无网或飞行模式下正常播放。
* **音频中断处理**：针对电话呼入、微信语音、其他媒体抢占播放焦点等场景，自动暂停，通话结束后恢复播放。
