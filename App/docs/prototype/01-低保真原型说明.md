# 松息低保真原型说明

## 设计依据

用户已批准 Direction 01。原型继承暖雾白、深松绿、琥珀强调、灰鼠尾草、软陶/纸张触感和有机大圆角。`今晚` 的信息层级保持不变；其余根页按 PRD 展开。

## 信息架构

- 根页：今晚、声音、睡眠、我的。
- 闭环详情：播放器、睡眠中、闹钟、报告、呼吸。
- 管理详情：下载、会员、权限、隐私与设置。
- 详情以原型对话层呈现，关闭后回到发起根页；根页之间始终通过唯一共享 Tab 切换。

## 根页骨架

1. 今晚：昨夜概览 → 推荐声景 → 开始今晚 → 快捷呼吸。
2. 声音：分类/收藏/下载 → 推荐声景 → 免费与锁定声景网格 → 离线入口。
3. 睡眠：开始睡眠 → 轻唤醒 → 基础报告 → 最近记录。
4. 我的：游客态 → 会员 → 下载/权限/隐私设置 → 非医疗声明。

## 响应与无障碍

- 原型以 390 × 844 pt 为审阅基线，在较窄屏保持单列。
- 主要触控目标不小于 44 × 44 pt；键盘焦点清晰。
- 支持 `prefers-reduced-motion`；信息不只依赖颜色表达。
- 深绿正文与暖白底保持高对比；琥珀只承担强调，不承载长文本。

## 可编辑实现约束

页面只有一个 `data-codex-root`；静态可编辑节点使用唯一稳定 `data-codex-id`；脚本不使用字符串 HTML 注入。四页共享一个 Tab DOM，不复制四套导航。
