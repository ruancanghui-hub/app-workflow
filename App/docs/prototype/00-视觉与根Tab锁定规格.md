# 松息视觉与根 Tab 锁定规格

## 决策与批准

- 批准来源：用户于 2026-08-28 明确选择 `direction-01-light-brand-generated-raw.png`，并要求首页不变、各 Tab 风格一致。
- 视觉基准：`App/output/brand-ip/songxi/04-core-tab-ui/direction-01-light-brand-generated-raw.png`。
- 角色基准：`App/output/brand-ip/songxi/01-character-concepts/character-anchor.png`。

## 不可变契约

1. 根 Tab 永远按 `今晚 → 声音 → 睡眠 → 我的` 排列。
2. 底部导航的外框、位置、高度、四等分布局、图标尺寸和文字基线保持一致；只允许当前项切换为深松绿激活态与琥珀点缀。
3. `今晚` 页面直接复用已批准原图，不重新生成、不重排。
4. 页面统一采用暖雾白背景、深松绿主色、琥珀强调、纸浆/软陶触感、超大圆角、柔和投影和克制角色露出。
5. 根页面只承载 PRD 的 P0/MVP 信息架构，不引入睡眠分期、诊断、课程、故事、混音或专注等 P1/P2/R&D 能力。

## 四个根页面

| 根 Tab | 页面骨架 | MVP 需求 |
|---|---|---|
| 今晚 | 昨夜时长、推荐声景、开始今晚、快捷呼吸 | 首页推荐、低摩擦开睡、呼吸引导 |
| 声音 | 免费/订阅声景、收藏、下载、离线提示、迷你播放入口 | ≥3 免费与锁定示例、试听、收藏、离线 |
| 睡眠 | 当前/下次唤醒、开始睡眠、昨夜基础小结、历史列表 | 会话、轻唤醒、时长/目标/主观评分 |
| 我的 | 游客/账户、会员、下载、权限、隐私与设置 | 订阅骨架、恢复购买、权限降级、合规入口 |

## 验收

- 四张根页画布同尺寸；首页文件校验保持不变。
- 四页底部 Tab 文案、顺序、外框和分栏一致，仅激活态不同。
- 文案无医疗诊断和未经验证的睡眠分期表达。
- 每个可交互入口在第三阶段需求追溯矩阵中有 P0 来源或明确标记为导航辅助。
