# ADR 001 — MVP Loop

- 状态：Accepted
- 日期：2026-08-28
- 产品：松息（songxi）

## 背景

用户要求参考潮汐并「完全复刻」。长期蓝图需保留潮汐级主模块，但首版必须有可验证闭环，且不得复制受保护资产。

## 决策

MVP 假设与闭环定为：

**选声景 → 开启睡眠会话 → 轻唤醒 → 查看基础报告**

麦克风分期/鼾声等进入 R&D；冥想课、故事、专注等进 P1；Watch/HRV 等进 P2。

## 否决条件（摘录）

- 未授权素材或视觉山寨潮汐  
- 医疗诊断/无证据准确率宣称  
- 权限拒绝导致无法伴睡  
- 整夜播放系统性失败  

详见 `App/docs/product/2026-08-28-松息/03-MVP范围.md`。
