# Performance & Polish Rubric

## Block release (FAIL)

- Main loop crash or data loss
- Blank screen >2s on warm start without skeleton
- Unhandled permission denial on required path
- Missing error UI on network failure for core action
- Text illegible at default Dynamic Type on primary screen

## Should fix (warn)

- Occasional jank on scroll
- Animation >400ms without reason
- Missing haptic on primary CTA
- Empty state without next action

## Nice to have

- Custom page transition curves matching brand
- Skeleton matching final layout
- Prefetch next step assets
