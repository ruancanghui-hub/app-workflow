隐私政策

更新日期：2026-09-06　·　生效日期：2026-09-06

云遥（以下简称「本应用」）由开发者运营。我们重视您的隐私。请在使用前仔细阅读本政策。

一、我们收集的信息

1. 本机身份：首次打开时在本机生成稳定的安装级标识与昵称，用于本地偏好，不依赖广告标识符（IDFA）。

2. 本地内容数据：睡眠监测会话、收藏声景、设置偏好、戒指配对与本地缓存的体征摘要等，默认仅保存在您的设备。

3. 诊断与分析（可选，经您同意后）：若启用 Firebase Analytics / Crashlytics，可能收集崩溃日志、设备型号、系统版本、粗略使用事件，用于稳定性与产品改进。

4. 广告（可选，经您同意后）：本应用使用 Google AdMob 展示开屏广告。广告 SDK 可能根据适用法律处理设备广告标识、粗略位置与互动数据。我们会在需要时请求 ATT / 展示同意表单。

5. 蓝牙戒指数据：在您主动配对并使用监测/播放功能时，本应用可通过蓝牙读取睡眠时长、心率等可穿戴数据，用于应用内展示。该等数据默认存于本机，不用于医疗诊断。

二、我们如何使用信息

  • 提供声景播放、睡眠监测报告、心率趋势、收藏与设置等核心功能；
  • 在您同意后改进稳定性与展示广告；
  • 遵守适用法律与 App Store / 监管要求。

三、共享与第三方

我们不会出售您的个人信息。为实现上述功能，可能涉及：

  • Google Firebase（分析 / 崩溃 / 远程配置）：https://firebase.google.com/support/privacy
  • Google AdMob（广告）：https://policies.google.com/privacy
  • 您配置的音频 CDN（仅用于拉取可播放音频文件）

四、数据保存与删除

本地数据随 App 卸载清除。您也可在「我的 → 设置与合规 → 删除本机数据」中清除本机云遥数据并重置同意状态。

五、非医疗声明

本应用为放松与 wellness 辅助工具，不提供医疗诊断、治疗或临床睡眠分期结论。如有健康问题请咨询专业医生。

六、儿童

本应用面向成人用户，不以儿童为主要对象。

七、联系我们

如对本政策有疑问，请通过 App Store 产品页所列开发者联系方式与我们联系。

八、政策更新

我们可能更新本政策；重大变更将通过应用内提示或版本说明告知。继续使用即表示您知悉更新后的政策。
