# App 模板（本仓术语）

本文件是本 **App 模板**仓的术语表。实现与文档一律使用下列用词。

## Language

**App 模板**:
可复用的 Flutter 工程起点，只面向 iOS 与 Android，以独立 git 仓库维护；不包含任一具体产品的业务领域。
_Avoid_: 脚手架、starter（口语可用，文档一律用「App 模板」）、业务工程

**模板实例**:
从 App 模板生成的一个具体 Flutter 应用工程，拥有自己的包名、Bundle ID 与业务代码。
_Avoid_: fork 出来的项目（除非特指 git fork）、子仓

**双端**:
仅指 iOS 与 Android 手机客户端；不包含 Web、桌面或平板专项适配承诺。
_Avoid_: 全平台、跨端（易被理解成含 Web/桌面）

**运维底座**:
App 模板中与具体产品业务无关、但每个模板实例都需要的可观测与运营能力集合；已定纳入**行为埋点**、**远程配置**（含功能开关）、**缺陷定位**与**帧卡顿监测**。以薄接口 + 适配器提供（行为埋点优先友盟，未配时再 Firebase / Fake），可替换。
_Avoid_: 基础组件（过宽）、中台、SDK 大杂烩

**行为埋点**:
把用户或系统触发的、预先定义的业务/交互事件上报，供分析与运营使用。
_Avoid_: 埋点（单独用时易与缺陷定位混淆）、统计、追踪、运营埋点

**友盟统计**:
行为埋点的一种供应商适配（`umeng_common_sdk`）；配置了双端 AppKey 时作为 `Analytics` 主实现，优先于 Firebase Analytics。密钥经**实例配置**写入 dart-define，勿提交仓库。
_Avoid_: 友盟推送/分享等非统计能力、双写多供应商事件

**应用内评分提示**:
手动触发的三按钮评分弹窗（好评 → 商店链接、差评 → **用户反馈页**、再用用看 → 关闭）；模板不自动弹，由 Catalog 演示或实例自行决定时机。
_Avoid_: 系统 in-app review、自动门控弹窗、商店评分 SDK

**用户反馈页**:
模板内简易反馈表单；提交仅 Toast + 行为埋点（不上报正文、不发 HTTP）。
_Avoid_: 客服工单、邮件反馈后端、内容审核

**远程配置**:
从远端下发键值或结构化配置（含功能开关），供模板实例在运行时改变行为而无须发版。
_Avoid_: 运营位、CMS、运营数据（过宽且易混进内容运营）

**功能开关**:
远程配置中的一类布尔（或等价）开关，用于打开/关闭某能力。
_Avoid_: 灰度（灰度是发布策略，未必等于开关本身）

**缺陷定位**:
把崩溃、严重错误与关键诊断上下文送达可查询的后端，供开发定位问题。
_Avoid_: bug 定位（口语）、日志（日志只是手段之一）

**帧卡顿监测**:
对主线程帧耗时超阈的采样与上报能力；属于**运维底座**，默认基于运行时帧计时，不默认绑定第二套 APM 供应商。
_Avoid_: 性能监控（过宽）、FPS 面板（偏开发工具）、卡顿监测（口语可，文档用本词）

**设计 token**:
与品牌无关的样式原子（色、字号、间距、圆角等）；可与默认 UI 库主题并存，供页面与薄封装消费。
_Avoid_: 组件库、UI Kit（指自研完整套件时）

**模板组件**:
App 模板默认 UI 层；以 **Forui** 为控件库（`lib/core/ui/ui.dart` 全量导出），并对按钮、弹框、加载、骨架、空态等高频能力提供 **App\*** 薄封装；不是第二套平行 UI Kit。
_Avoid_: 自研完整组件库、与 Forui 重复的 Material 包装层

**动效套件**:
App 模板默认动效依赖组合：**animations**（页面过渡）、**shimmer**（骨架页）、**lottie**（AE 复杂动画）、**rive**（交互驱动动画）；资源与具体编排由模板实例按需使用。
_Avoid_: flutter_animate（本仓已改用本套件）、随意再加第三动画运行时

**启动品牌页**:
冷启动后、进入业务首页前的 Flutter 品牌过渡页，展示实例可配置的标识、slogan、版权与初始化加载；与系统原生启动图衔接，消灭白屏之外的品牌瞬间。
_Avoid_: Splash（文档可用英文技术名，中文优先本词）、闪屏、开屏广告（非本能力）

**引导页**:
首次安装或引导版本号 bump 后、进入首页前的轮播介绍页；完成状态写入本地 KV（`onboarding_seen_version`），与 `APP_ONBOARDING_VERSION` 比对决定是否展示。
_Avoid_: 开屏广告、权限引导（非本能力）、实例接入清单 ONBOARDING.md（文档用词不同）

**诊断入口**:
用于查看应用健康与运行时诊断信息的隐藏或受限界面；`dev` 构建变体可常驻可达，`prod` 仅通过约定手势（及可选功能开关）进入。
_Avoid_: 调试面板、隐藏入口（口语可，文档用本词）、flutter_ume 类开发工具箱

**构建变体**:
同一代码库面向不同运行环境的打包配置；App 模板默认仅含 `dev` 与 `prod`。
_Avoid_: flavor（文档可用英文技术名，中文语境优先「构建变体」）、环境（过宽）

**模板源**:
本仓中用于生成模板实例的唯一工程蓝本目录（约定为 `template/`）；不是可手改的长期业务工程。消费方式见 `docs/flutter-create-template-conventions.md`。
_Avoid_: 示例 App（禁止与模板源双份维护）

**应用实例身份**:
每个模板实例在运营侧的唯一标识（如 appId）及展示名等元数据，用于把客户端上报归到「哪一个应用」。
_Avoid_: 包名、Bundle ID

**应用运营台**:
运营者查看多个模板实例运营情况的后台；本仓只提供客户端上报能力，不含服务端。
_Avoid_: 运营位、CMS、Firebase 控制台

**实例接入清单**:
从 App 模板生成模板实例后，用于登记外部申请项与本机/CI 填写位置的检查表；模板仓以 `docs/instance-onboarding-checklist.md` 为蓝本，实例根目录复制为 `ONBOARDING.md`。
_Avoid_: README、运维手册（过宽）

**实例配置**:
模板实例根目录的唯一配置文件 `instance.config.yaml`；经 apply 脚本展开为 dart-define、签名与 Fastlane 环境文件。
_Avoid_: .env（其为生成物）、散落的 Secrets / key.properties 手填源

**发布流水线**:
模板实例通过 Fastlane + GitHub Actions，将 **prod 构建变体** 自动构建并上传至 TestFlight / Play Console 的交付路径。
_Avoid_: CI（过宽；分析/单测 CI 与发布流水线分开表述）
