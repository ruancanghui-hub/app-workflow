# Mist Orbit · Core Tab Redesign Brief

- **Product:** a Chinese-language mobile companion for rest, meditation, ambient sound, and daily regulation.
- **Audience:** people seeking a calm, low-pressure reset during evenings, transitions, and focused pauses.
- **Core journeys:** discover a next useful ritual, start sleep content, choose a meditation path, and play an ambient soundscape.
- **Navigation:** 首页 / 睡眠 / 冥想 / 声音.
- **Visual constraints:** retain the references’ calm vertical hierarchy and four-tab navigation; replace all reference branding, copy, imagery, and icons with an original system.
- **Non-goals:** no social feed, health diagnosis, pricing claims, or competitor branding.

The request asks to redesign all four supplied core tabs without a selection pause. The selected direction is **雾林星球 / Mist Orbit**: a small, glowing orb-like “rest guide” appearing only as a subtle status anchor, not as a dominant mascot.
